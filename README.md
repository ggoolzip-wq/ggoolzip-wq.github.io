# 보스 캐릭터 관리 (KMS) — 사용법

**온라인 주소: https://ggoolzip-wq.github.io/** (설치 없이 어디서나 접속, 구글 드라이브 동기화 지원)
내려받은 `index.html` 파일을 더블클릭해서 써도 똑같이 동작합니다(구글 동기화만 온라인 주소 전용).

## 1. 기본 사용 (설치 필요 없음)
1. `index.html` 파일을 더블클릭해 크롬/엣지에서 엽니다. (파일 하나로 동작, 인터넷 없이도 체크·계산 가능)
2. 왼쪽 **+ 추가**로 캐릭터를 직접 추가하거나, 아래 2번처럼 넥슨 API로 불러옵니다.
3. 데이터는 이 브라우저에 저장됩니다. 집·PC방 등 다른 PC와 같이 쓰려면 온라인 주소에서 **구글 로그인**(드라이브 동기화, 아래 6번)을 하세요.
   이번 주 주간 보스를 **12/12** 다 잡은 캐릭터 카드는 반투명 검정으로 덮이고 **★ 이번 주 보스 완료**가 표시됩니다. 검은 마법사를 선택해 두었는데 이번 달 아직 안 잡았으면 그 아래 줄에 빨간 **(!) 검마 격파 필요**가 함께 나옵니다. 마우스를 올리면 덮개가 사라지고, 클릭·✎·▲▼·끌어서 순서 바꾸기는 그대로 됩니다.
4. 캐릭터 순서: 카드 왼쪽 **⠿ 손잡이를 끌어서**(휴대폰은 손잡이를 누른 채 이동) 또는 **▲/▼** 버튼으로 바꿉니다.
   같은 월드 안에서 순서를 바꾸고, 월드 제목 줄의 ⠿ / ▲▼ 로 월드 순서도 바꿀 수 있습니다. 동기화·불러오기·본캐 지정을 해도 순서는 그대로입니다.
5. **보스 체크** 탭 오른쪽 패널에 이번 주 전체 수익과 캐릭터별 수익이 나옵니다. 주간 수익 = 이번 주 클리어한 **주간 보스**의 결정석 가격 ÷ 파티 인원의 합계(캐릭터당 12회까지, 월드 판매 한도는 계산하지 않음). (좁은 화면에서는 아래쪽)
6. **희귀 드롭 획득 기록**: 보스 행의 아이템 칩을 누르면 그 캐릭터의 이번 주 획득 개수가 +1 됩니다.
   칩의 **−** 버튼(또는 우클릭)으로 1개 취소. 드롭은 **개수만** 기록하고 수익(결정석)에는 넣지 않습니다.
   오른쪽 패널·주간 기록·총 수익 탭에서 캐릭터별/주별/아이템별 획득 개수를 볼 수 있습니다.
   **반지 상자**(녹옥/홍옥/흑옥/백옥/생명)를 누르면 결과 창이 뜹니다: 리스트레인트 링 4레벨 / 컨티뉴어스 링 4레벨 / 둘 다 못 먹음.
   고르면 +1과 결과(리4·컨4·꽝)가 함께 기록되고, 리4·컨4면 축하 연출이 나옵니다. ✕·Esc·바깥 클릭은 아무것도 기록하지 않습니다.
   −(취소)는 가장 최근 획득과 그 결과를 지웁니다. 이 기능 이전에 기록한 반지 상자는 '미기록'으로 표시됩니다.
   드롭 기록은 그 보스의 **파티 인원** 설정을 따릅니다. 솔로(1인)는 '흑옥의 보스 반지 상자 ×1', 파티는 '흑옥의 보스 반지 상자 (2인 분배) ×1'처럼 표시되고,
   모든 화면(보스 행·오른쪽 패널·주간 기록·총 수익)에서 같은 형식·같은 개수로 보입니다. 이번 주/이번 달 중에 파티 인원을 바꾸면 그 보스의 이번 기간 기록도 함께 바뀌며,
   주간/월간 초기화로 기록에 저장된 뒤에는 그때의 인원으로 고정됩니다.
7. **총 수익** 탭: 처음 기록한 주부터의 누적 수익(주간 보스 + 월간 보스 별도), 모든 주의 막대 그래프와 누적선,
   캐릭터별 누적, 아이템별 누적 획득 개수(반지 상자는 리4·컨4·꽝 집계와 대박 확률), 전체 주 목록. 주간 기록은 자동으로 지워지지 않으며 구글 드라이브 동기화에 포함됩니다.
   월간 보스(검은 마법사)는 주간 수익에 넣지 않고 **'이번 달 월간 보스'** 로 따로 보여 주며, 매월 1일 초기화 때 **주간 기록** 탭의 '월간 보스 기록'에 저장됩니다.
8. **일퀘 현황** 탭(상단 '총 수익' 뒤 ㅡ 다음): API 키가 연결된 캐릭터별로 메이플 스케줄러의 오늘 일퀘 진행을 카드로 보여 줍니다.
   항목: 세르니움·아르크스·오디움·도원경·아르테리아·카르시온·탈라하트·기어드락 일일 퀘스트, 몬스터파크(캐릭터당 하루 7회 기준), 익스트림 몬스터파크(주간 퀘스트 n/5).
   - 칸마다 지역 아이콘(어센틱/그랜드 어센틱심볼, 몬스터파크 이용권, 익몬은 몬스터파크 NPC 슈피겔만)이 이름 왼쪽에 있고, 글자는 가운데 정렬입니다.
   - 완료한 칸은 보스 완료 카드처럼 **반투명 검정 덮개 + ✓ 완료**, 마우스를 올리면 덮개가 사라지고 원래 칸이 보입니다.
   - 레벨이 모자란 지역은 칸 대신 카드 아래 🔒 줄(예: 탈라하트 Lv.290)로 표시합니다. '미수락' = 스케줄러 상태 "기타"(아직 받지 않음 등).
   - 오른쪽 위 **편집**: 위쪽 칩으로 항목을 전체 캐릭터에서 켜고 끄기, 카드의 칸을 눌러 그 캐릭터에서만 숨기기, 👁 로 캐릭터 카드 숨기기. 다시 **완료**를 누르면 닫힙니다.
   - 탭이 열려 있으면 10분마다 자동 갱신(넥슨은 캐릭터 접속 중·접속 종료 때 갱신). 같은 호출로 보스 자동 체크도 함께 반영됩니다.
9. **길드 현황** 탭: 스카니아 **봉사활동** 길드의 지하 수로·플래그 레이스 점수와 순위, 길드 레벨·마스터(넥슨 길드 랭킹, 하루 1번 09:30경 갱신 — 오늘 자료가 아직 없으면 어제 자료와 기준일 표시),
   아래에 **★ 본캐**의 이번 주 지하 수로 점수(스케줄러 '[길드] 지하 수로')와 플래그 레이스·주간 미션 포인트. 길드 이름·월드는 고정값입니다(바꾸려면 요청).

## 2. 넥슨 Open API 연동 (본캐·부캐 불러오기 + 보스 자동 체크)
1. https://openapi.nexon.com 에 넥슨 ID로 로그인합니다.
2. **마이 페이지 → 애플리케이션 등록** → 게임: 메이플스토리 → API 키 발급 (애플리케이션 상세 화면에서 복사).
3. 왼쪽 **캐릭터** 옆 **+ 추가** → 창 위쪽 **🔑 넥슨 API 키**에 이름(예: 본계정)과 키를 넣고 **+ API 키 추가**.
   추가하자마자 아래에 그 계정의 **캐릭터 목록**이 나옵니다. 등록한 키는 가려서(live_••••abcd) 보이고, 계정 줄의 **캐릭터 목록**/**삭제**로 관리합니다.
   - **부계정이 있으면 계정마다 키를 따로 등록**하세요. 캐릭터 목록·보스 자동 체크는 그 키를 발급한 계정의 캐릭터만 조회됩니다.
4. 목록에서 캐릭터 여러 명 체크(검색·레벨·월드 필터 가능) → **선택 추가**. API 키 없이 넣으려면 창 아래 **이름으로 직접 추가**.
   이미 추가한 캐릭터 수정은 카드의 **✎**.
5. 상단 **↻ 동기화** 버튼을 누르면(마지막 동기화 시각은 버튼에 마우스를 올리면 보임) 게임 내 "메이플 스케줄러"의 보스 완료 정보로 클리어가 자동 체크되고,
   레벨·직업·이미지·**현재 경험치(%)**도 갱신됩니다. 페이지를 열어 두면 15분마다 자동 동기화합니다.

### 알아 두세요
- 보스 자동 체크는 **내 계정 캐릭터**만, **2026-06-25 이후 한 번 이상 접속한 캐릭터**만 됩니다. 안 되는 캐릭터는 ⚠ 표시 — 손으로 체크하면 됩니다.
- **파티 인원은 API로 알 수 없어서** 보스마다 직접 골라야 합니다(결정석 분배 계산용).
- 레벨·경험치 등 기본 정보는 넥슨 API 기준 시점 데이터라 게임과 약간 차이가 날 수 있습니다. 직접 추가한 캐릭터는 경험치 막대가 표시되지 않습니다.
- API 키는 이 브라우저(localStorage)와, 구글 드라이브 동기화를 켠 경우 내 드라이브의 앱 전용 숨김 폴더에 저장됩니다. API 호출은 항상 브라우저에서 open.api.nexon.com 으로 직접 합니다. 공용 PC에서는 쓰고 나서 **로그아웃 후 이 PC 데이터 지우기**를 누르세요.

### 키를 넣었는데 캐릭터가 안 나올 때
캐릭터 목록 창에 결과가 그대로 표시됩니다.
- **"계정 캐릭터가 0명입니다"** (호출은 성공): 
  1. 키를 발급한 **넥슨 ID**가 게임 캐릭터가 있는 넥슨 ID와 같은지 확인하세요. 캐릭터 목록은 *본인 API 키로만*, 키를 발급한 계정의 캐릭터만 나옵니다
     ([공지 2024-06-07](https://openapi.nexon.com/ko/support/notice/2580334/)).
  2. 키가 `test_`로 시작하면(개발 단계) 본인 계정 데이터가 비어 있다는 사용자 보고가 있습니다
     ([mapleaudit 가이드](https://www.mapleaudit.com/guide), 비공식). 애플리케이션을 **서비스 단계(`live_`)** 로 다시 발급해 보세요
     ([사전 준비 가이드](https://openapi.nexon.com/ko/guide/prepare-in-advance/): 개발 단계 초당 5회·하루 1,000회, 서비스 단계 초당 500회).
  3. 새 캐릭터·새 키는 반영까지 시간이 걸릴 수 있습니다(게임 데이터 평균 15분). 잠시 후 **다시 불러오기**.
- **오류 코드가 보일 때** ([응답 코드표](https://openapi.nexon.com/ko/guide/request-api/)):
  `OPENAPI00005` 잘못된 키(복사 실수·재발급된 키) · `OPENAPI00002`(403) 권한 없음 · `OPENAPI00007`(429) 호출량 초과 ·
  `OPENAPI00009` 데이터 준비 중 · `OPENAPI00010` 게임 점검 · `OPENAPI00011` API 점검. "네트워크 오류"면 인터넷 연결과 광고 차단 등 브라우저 확장 프로그램·네트워크(회사/학교/PC방)의 차단 여부를 확인하세요.
- 그래도 안 되면 **+ 추가** → 이름 입력 → **API 조회**로 한 명씩 추가할 수 있습니다.

## 3. 결정석 가격 · 한도 출처
- 처치 한도: 캐릭터당 주간 보스 12회, 월간 보스 1회 (고정).
- 기본 가격: 메이플스토리 공식 **2026-09-17 업데이트 안내 '보스 리워드 개편'** 표 값 그대로 — https://maplestory.nexon.com/News/Update/813
  (검은 마법사 가격은 공지대로 2026-10-01부터 적용된 값). 이후 가격은 아래 5번처럼 자동 갱신됩니다.
- 힐라(하드)·핑크빈(카오스)·시그너스(노멀)는 2026-06-18 패치(https://maplestory.nexon.com/News/Update/806)로 일일 보스가 되었고 시그너스(이지)는 삭제되어 목록에서 뺐습니다. 기존 저장 데이터에서도 자동 정리됩니다.
- 같은 공지에서 "캐릭터당 주간 결정 판매 12개 제한"은 삭제되었습니다. 앱의 "주간 12"는 캐릭터당 주간 보스 **처치** 횟수 제한입니다.

## 5. 결정석 가격 자동 갱신
- 온라인 주소에서는 따로 할 일이 없습니다. 사이트의 `prices.json` 을 GitHub Actions(`.github/workflows/update-prices.yml`)가 **매일 12:17(KST)** 에
  메이플스토리 공식 업데이트 공지(https://maplestory.nexon.com/News/Update)에서 '강렬한 힘의 결정' 가격표를 읽어 갱신하고, 페이지를 열면 자동으로 반영됩니다.
- 가격은 **직접 수정할 수 없습니다** (가격 수정 기능 없음). 예전에 직접 고친 가격이 있었다면 자동으로 지우고 공식 가격을 씁니다.
- 공지에 적용일이 있으면(예: 검은 마법사 2026-10-01부터) 그날부터 적용합니다.
- **보스 체크** 탭 오른쪽 '결정석 가격' 카드(강렬한 힘의 결정 아이콘)에 보스별 가격이 싼 순서로 나오고, 아래에 '공식 패치 노트 기준 자동 갱신 (마지막 확인 YYYY-MM-DD)'이 표시됩니다.
- 공식 홈페이지를 못 읽거나 형식이 바뀌면 이전 가격을 그대로 씁니다. 파일(file://)로 연 경우에는 내장 기본 가격(2026-09-17 공지)을 씁니다.
- 가격표 해석기는 `scripts/nexon_prices.py`, 갱신 스크립트는 `scripts/update_prices.py` 입니다(파이썬 표준 라이브러리만 사용).

## 6. 구글 드라이브 동기화 (집 ↔ PC방 같은 데이터)
- 온라인 주소에서 상단 **☁ 구글 로그인** 버튼 → 작은 메뉴의 **구글 로그인**을 누르고 구글 계정을 선택·허용합니다.
- 저장 위치: 내 구글 드라이브의 **숨겨진 앱 전용 폴더**(appDataFolder)에 `maple-boss-tracker.json` 한 파일. 드라이브의 다른 파일은 보거나 건드리지 않습니다(권한: drive.appdata).
- 로그인할 때:
  - 드라이브에 데이터가 있고 이 PC가 비어 있으면 → 자동으로 불러옵니다.
  - 이 PC에만 데이터가 있으면 → 드라이브에 처음 저장합니다.
  - 둘 다 있고 내용이 다르면 → 양쪽의 **마지막 수정 시각·캐릭터 수**를 보여 주고 한 번 묻습니다: **드라이브 데이터 불러오기 / 이 PC 데이터로 덮어쓰기**.
    한 번 연결한 뒤에는 한쪽만 바뀐 경우 묻지 않고 자동으로 맞춥니다(다른 PC에서 바뀌었으면 불러오기, 이 PC에서만 바뀌었으면 저장).
- 그 뒤로는 변경 후 약 **5초** 뒤, 그리고 탭을 닫거나 다른 탭으로 갈 때 자동 저장합니다. 상단 버튼에 '☁ 17:05 저장됨'처럼 마지막 저장 시각이 보입니다.
  저장 직전에 다른 PC가 그 사이 저장한 것을 발견하면 덮어쓰지 않고 다시 묻습니다.
- 다음에 페이지를 열면 자동으로 다시 연결합니다. 브라우저가 로그인 팝업을 막으면 상단 **☁ 다시 연결**을 한 번 누르세요(구글 정책상 처음 열 때 한 번 클릭이 필요할 수 있음).
- 캐릭터·체크·드롭·기록·설정 전체와 **넥슨 API 키도 함께 저장**됩니다(내 드라이브 앱 전용 숨김 폴더, 이 앱만 읽을 수 있음). 다른 PC에서 로그인하면 키도 자동으로 복원됩니다.
- 상단 ☁ 메뉴에서 **로그아웃**할 수 있습니다(이 브라우저의 데이터는 지우지 않습니다. PC방 PC는 종료할 때 자동으로 초기화됩니다).
- 파일(file://)로 연 페이지는 구글 로그인이 안 됩니다. 온라인 주소에서 쓰세요.
